HBA Upgrade and Proxmox Installation

By: Rody Davis

Today was a productive day for server maintenance and upgrades.

Hardware Upgrades

I successfully installed the HBA 9305-24i. It worked perfectly on the first try after being installed into the server. This provides the necessary connectivity for the expanded drive capacity.

To ensure the HBA stays cool in a silent system with low airflow, I 3D printed a custom fan cover using ASA filament. This cover accommodates a 20mm Noctua fan, providing targeted cooling without compromising the system's low noise floor.

Software Setup

I've also reached a major milestone with the software setup: Proxmox is now installed on the pair of Intel drives. This provides a solid foundation for the virtualized environment.
