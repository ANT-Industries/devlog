Troubleshooting the HBA Broadcom 9400-16i & SAS Upgrades

On this day I was able to troubleshoot the 9400-16i and found out that I have a broken or clone card which was white I got green flashing lights after post, but nothing i could do would get it to show up in BIOS (even EFI shell).

I ordered a 9305-24i from "The Art of the Server" on eBay and should be a much better card.

Turns out there are a lot of clones on the market coming from China and there is a huge price gap under $200 and over $500. My 9400-16i was $135 which I though was the correct price for used.

DevLog Improvements

Today I've transformed the DevLog from a collection of Markdown files into full-blown microsite generated with Dart.

Microsite Architecture

  • Static Site Generator: Built a custom SSG in Dart (scripts/build_site.dart) that parses markdown and frontmatter.
  • Templating: Switched from manual string replacement to Mustache for better structure.
  • Improved UI:
    • Sidebar: High-speed navigation to recent logs.
    • Pagination: Chronological browsing for log entries.
    • Premium Aesthetics: Dark mode, "Outfit" typography, and responsive grid layout.

Developer Experience

  • Live Rebuilds: Implemented a scripts/dev_server.dart using the watcher package to automatically rebuild the site on any change.
  • Link Verification: Created a scripts/check_links.dart tool to ensure all internal links and assets are valid before deployment.
  • CLI Power: Added ArgParser to the build script for easy configuration of base paths and GitHub usernames.

Deployment & CI/CD

  • GitHub Actions: Configured a workflow (.github/workflows/deploy.yml) to automatically build and deploy to GitHub Pages on every push to main.
  • Concurrency Support: Added concurrency rules to prevent race conditions during rapid deployments.
  • RSS Feed: Added an automated RSS feed generator (rss.xml) so you can follow the log in your favorite reader.
